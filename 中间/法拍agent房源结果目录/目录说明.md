## 使用规则

1. Agent 恢复或复核时，以程序状态文件指向的真实编号批次为准，不得把其他批次文件复制进去冒充断点。
2. 数据整理阶段可以读取多个来源批次，但必须形成一个唯一输入和一个 `manifest.json` 后才能交给产物阶段。
3. 产物执行者不得扫描整个结果目录，只能从指定日期的 `manifest.json` 领取任务。
4. 采集目录中的原始 JSON、证据和复核文件不得因已生成产物而删除。
5. 归档目录不是当前数据源；恢复归档前必须得到用户明确授权。
