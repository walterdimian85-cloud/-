## 4. 踩过的坑（每条 = 一个规则，按环节分）

### 4.2 采集（阿里列表页）
- **列表卡片字段不全，很多信息在 `card_title` 原文里**（小区名/面积/评估价：`滨江国际 | 266.53m²`、`房产小区名:滨江国际（星城）`、`评估价 ¥2.48万`）——**必须提取 card_title，不要只取结构化字段**
- JS 正则别用非捕获组 `(?:...)` 取捕获值 → `m[1]` undefined 整个 evaluate 抛异常；要捕获就写外层捕获组
- 详情页开拍时间格式：**"距开始 XX天 (2026-09-28 10:00开拍)"**，正则 `(\d{4}-\d{2}-\d{2} \d{2}:\d{2})开拍`（旧格式"网拍开始时间：YYYY/MM/DD"已失效）
- 详情页面积：`建筑面积170.93㎡`；储藏间公告"建筑面积6.56"（**无 m² 后缀也能匹配**，正则别加死后缀）；车库/储藏间面积在公告文本里
- **淘宝高频访问触发验证码拦截**（页面文本变"验证码拦截"）：停 1-2 分钟 + 换会话重试；批量采集控制频率
- bsk 会话长时间运行会失效 → `bsk session start --browser <id>` 重建

### 4.3 解析 / 合并（merge）
- 区域解析：禁止用 `[\u4e00-\u9fa5]{2,3}(?:区|县|市)` 这类宽松正则——"址**在永春**县"会被匹配成"在永春"。区域必须用带后缀全名（永春县/惠安县）且从权威字段取
- 小区名：**优先 card_title"房产小区名:"→ 次优"| XX | NNm²"模式 → 再兜底小区名称清单（926条）→ 最后品牌名（`卓辉·金色外滩`）**；禁止"路/街/号后截中文段"
- 区县列表正则要**限定已知区县集**，否则"| 起拍价 |"会被当区县
- **评估价单位必须统一"万"**：本次 08-30 补采批存"元"（24869）、08-31 初始批存"万"（91.3674）→ 生成时统一按元再÷10000 → 全变 0、折扣×10000（64→64000折）。源头 JSON 修一次，后续生成不再犯
- merge 脚本**二次运行读被覆盖的旧输出**会串日期（setdefault 覆盖）→ 别对同一输入跑两次，或修主输入
- 结拍日跨多天的批次：make_records_summary **去掉单日过滤全量收**，结果 HTML 按结拍日建多日期组

### 4.4 生成 / 回填 HTML
- 福州结果 HTML 是**单 table**（成交+流拍同表，无 fail-h div）；且历史文件有**嵌套 `<tbody>`** → 正则必须贪婪匹配 `<tbody>(.*)</tbody>`，否则截断文件
- day-sep"成交/流拍"字样在 `<i>` 标签内，`[^<]+` 提取不到 → **去标签取完整标题**
- 同一天被拆多组（4+3+12 成交 / 10+17 流拍）→ 按 `(\d+月\d+日)` **纯日期比较**合并（含条数的 date 字符串比较会失败）
- "NaN月0日"组 = 日期解析失败残留，按上下文归属正确日期
- 回填判断"空值"要用 `in ('', '暂无')`，"暂无"不是已有值
- Excel 合并单元格（MergedCell）不可写 → 定位合并锚点写左上角；delete_rows 会破坏合并 → **先修字段、最后删行、删前 unmerge**

### 4.5 飞书
- **优先走 feishu_sync.py 正式脚本**（格式/千分位/去重/幂等内置），手动 batch-update 仅小修补
- batch-update 稳定方式：脚本只生成 JSON，Bash 用 `lark-cli sheets +batch-update --operations - < file --yes` 重定向 stdin（subprocess input 方式报 "--operations is required"；传文件路径报 invalid JSON）
- 删行用 `+dim-delete --range 23:23 --yes`（无 --dimension flag）；**batch-update 先执行、dim-delete 后执行**，行号才对
- `csv-get` 单次响应 ~2600 行上限 → **读全量必须分块**（read_all，step 2600）
- 千分位带引号字段必须 `csv.reader` 解析，不能 `split(',')`
- subprocess 调 lark-cli 需 `shell=True`（managed python PATH 不含 lark-cli）
- 飞书操作一律以用户最新编辑版为准，不回退旧内容

### 4.6 环境
- Python 路径一律 `E:/盘符/...`（Windows 下 `/e/` 会被解析成 `E:\e\`）
- 产品 HTML 与法拍库 HTML **两份都要同步**（cp + md5 校验），feishu_sync 只读法拍库
- openpyxl 写文件被腾讯文档预览占用会 PermissionError → 等预览关闭或先写 tmp 再覆盖
