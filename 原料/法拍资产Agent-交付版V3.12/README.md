# 法拍资产 Agent（MVP）

本目录是在稳定的“法拍房 Skill V2”之上的单 Agent 编排层。V2 继续负责确定性的列表扫描、高水位、详情采集、逐条落盘和 Excel 生成；Agent 负责监工、异常恢复、集中 AI 复核、历史归档、初步关注线索和每日摘要。`runtime/fujian-auctions-v2` 是从只读稳定版复制的内置采集引擎，Agent不会修改外部原始V2目录。

## 当前边界

- 用户点击后才启动，不定时自动运行。
- 最长运行 4 小时；V2 与 Agent 两层自动恢复，最多 5 次。
- 超过 500 个本轮处理链接暂停并要求核对高水位；超过 800 个强制停止。
- 验证码、滑块、账号密码和短信码只允许用户人工处理；等待 1 小时后暂停。
- 只有全部高水位命中、无采集失败且 V2 成功推进状态后，才进入 AI 集中复核。
- AI 优先复核面积、标的名称和小区名称；其他字段只有高置信度且有原文证据时才能自动更正。
- AI 更正会保留更正前快照、证据、置信度和变更日志。
- AI复核采用服务商适配层：支持DeepSeek、OpenAI、Anthropic Claude、Google Gemini、阿里云百炼及自定义OpenAI兼容服务。模型名、API地址和密钥必须来自同一服务商；未配置可调用API的模型不能仅凭名称运行。
- “初步关注标的”只基于当日相对低起拍单价或竞买热度，不构成估值、尽调或投资建议。
- 当前只在本地生成日报；向负责人发送的渠道需后续配置企业邮箱、Teams等接口。
- 支持安全暂停：完成并保存当前详情页后停止；恢复时复用当天断点。
- 页面可只读输出并复制12条生产高水位。
- 页面可生成WorkBuddy、Codex及其他AI工作台的标准运行指令；所有入口调用同一Agent CLI。

## 核心流程

`用户点击 → V2采集与断点保存 → 高水位完成检查 → AI疑难字段复爬 → 高置信度校准/低置信度待复核 → 重建Excel → 历史库 → 摘要与异常报告`

## 目录说明

- `bin/`：命令入口。
- `src/`：Agent编排、监工、AI复核、历史库和报告。
- `public/`：本地操作页面。
- `runtime/fujian-auctions-v2/`：Agent内置的V2稳定采集引擎副本。
- `config/`：不含密钥的配置示例；首次运行生成本机配置。
- `references/`：业务边界和AI复核规则。
- `tests/`：不联网的核心测试。
- `agent-data/`：运行后产生的Agent状态、历史库和日志，不应打包交付。

## API复核与工作台复核

- API复核：Agent在采集完成后直接调用所选服务商，自动复核并更新Excel；适合无人值守，但会产生API费用。
- 工作台复核：Agent只导出候选记录、规则和断点文件，不调用API。用户在页面复制Codex或WorkBuddy复核口令，由工作台读取网页证据并逐条保存结果；全部完成后统一校验并更新Excel。
- 工作台结果未覆盖全部候选链接时，`review-apply`会拒绝生成完成状态，避免把未复核完的数据误报为完成。
- 全省标准采集与小范围定制采集使用不同状态空间；重置当前范围高水位不会覆盖另一种任务的高水位。
# 2026-08-11 任务批次与小范围采集

- “已采集”显示当前任务批次，不再把同一天早先中断任务的历史数量直接累加。
- 默认不再执行一轮独立预扫描；正式采集在扫描高水位列表时同步形成计划量，避免同一批列表重复扫描两遍。
- 采集和Excel完成后必须停在“等待选择复核方式”，由用户明确选择API、Codex/WorkBuddy工作台或暂不复核；该选择只启动复核阶段，不会重新进入采集。
- “开始新的采集”会自动建立独立批次、将本次计数归零并立即采集；“继续上次采集”只在存在中断断点时显示。
- 同一天再次点击“开始新的采集”时，不会改名或混写第一次结果；目录依次使用`YYYYMMDD（1）`、`YYYYMMDD（2）`。
- 500 条暂停提示核对高水位，800 条强制停止。
- 支持全省标准采集和小范围定制采集。小范围任务使用独立状态目录，不改动全省 12 条高水位。
- 小范围任务可选择平台、类别、省份和一个或多个地级市；每个“平台 × 类别 × 城市”填写两条状态高水位。
- 正式详情采集前先扫描列表，高水位命中后显示各组计划量，并按每条 5–7 秒估算用时。
- 页面实时显示各组“等待扫描、高水位已命中、采集中、已完成、高水位未命中”等状态。
- 新增“阿里资产（PC端）”采集通道，与原阿里入口互斥，可与京东组合；PC端按物业类型组合、是否包含破产资产、地区和状态使用独立高水位。
- PC端列表优先提取小区名称、面积、户型、评估价和价格证据，详情页继续作为起拍价、成交状态及其他业务字段的权威来源。
