# 法拍资产 Agent 0.1 使用说明

## 小范围采集与独立高水位

- 先选择省份，再勾选平台、类别和一个或多个地级市。京东拍卖会先选择省份，再把第二级“全省”切换为当前任务的地级市；若页面没有真实选中该城市，程序会停止该组，避免混入全省数据。
- 每条高水位输入框后都有“保存本条”。已输入内容还会保存在浏览器本机草稿中，增加城市或类别不会清空原值。
- 如果取消某个包含未保存链接的城市、平台或类别，页面会列出受影响链接，可先复制；选择取消则恢复原采集范围。
- “调用相同范围上次高水位”只匹配完全相同的省份、城市、平台和类别。不同小范围各有独立档案，不会互相覆盖，也不会修改全省12条生产高水位。
- 小范围任务完成后，程序会将本次最新高水位写回该范围的独立档案，同时保留“上次小范围爬取高水位”供查看和复制。

## 第一次使用

1. 安装 Node.js 20 或更高版本。
2. 准备一个可调用的AI服务商API。Agent支持DeepSeek、OpenAI、Anthropic Claude、Google Gemini、阿里云百炼以及自定义OpenAI兼容服务。
3. 双击《启动法拍资产Agent.cmd》。首次运行会自动安装本地依赖，然后打开本地操作页面。
4. 内置采集引擎通常无需修改。请选择：
   - 采集状态目录：保存12条高水位、采集断点和独立 Edge 登录状态；
   - 房源结果目录：今后每日 Excel、摘要和异常报告的保存位置。
5. 在“AI服务商”中选择实际提供API的厂商。模型下拉框提供常用预设；下方输入框用于模型不在预设中时填写准确模型ID。API地址会自动填写，普通用户通常无需修改。
6. 把真实API Key粘贴到“API Key”。默认勾选“使用Windows当前账号加密保存”：Agent通过Windows DPAPI保存密文，以后启动时自动读取，配置、日志和Excel中都没有明文。换电脑或换Windows账号后需要重新输入。取消勾选则只在本次程序内存中使用。
7. 预设模型只用于方便填写，服务商可能更新或下线模型；控制台显示的模型ID优先。HY3等模型只有在部署平台提供API地址、模型ID和密钥时，才可通过“自定义OpenAI兼容服务”接入。
8. 保存配置。确认前一日12条高水位已齐全后，点击“开始今日采集”。Agent不会定时自动启动。

## 运行过程中

- 点击“完成当前标的后暂停”后，Agent不会立即强行终止页面，而会等待当前详情页完成，并确认JSON进度与采集中Excel均已更新后再暂停。点击“恢复任务”会跳过已保存链接继续采集。
- “输出高水位链接”只读显示当前生产状态中的12条链接，便于核对；该按钮不会推进或修改高水位。
- 如需在WorkBuddy、Codex或其他AI工作台中运行，可在页面选择工作台并复制标准指令。网页和工作台调用同一个CLI、配置、断点及高水位。
- 任务最长运行4小时；采集器和Agent均会监控断点，异常后自动续爬，最多重试5次。
- 出现滑块、验证码、登录或短信验证时，只能在弹出的 Edge 中人工完成；Agent不会自动绕过验证。
- 人工验证超过1小时未处理，任务会暂停并保留断点。
- 已处理链接超过500个时，Agent暂停并要求核对高水位；确认链接正确后点击“确认高水位并续爬”。
- 本轮已处理链接超过800个时强制停止，避免错误高水位造成无限历史扫描。
- 疑难记录不会阻塞主采集；高水位全部完成后，Agent集中复爬并复核面积、标的名称和小区名称。

## 完成条件与交付物

只有全部高水位命中、无采集失败、V2状态成功推进后，才算采集完成。完成后在当日结果目录查看：

- 更新后的 Excel 工作簿；
- 《每日摘要与异常报告.md》；
- `Agent数据摘要.json`；
- `Agent异常报告.json`；
- `AI复核变更.json`；
- `Agent初步关注标的.json`。

异常报告会说明哪些字段原程序未找到、AI读取了什么页面证据、哪些内容已自动校准，以及哪些记录仍需人工复核。AI低置信度建议不会直接覆盖工作簿。

当前版本仅在本地生成摘要，尚未配置自动发送渠道。后续可按企业要求接入邮箱、Teams或内部系统。

## 选择AI复核方式

1. 采集与Excel生成完成后，Agent先停止在“等待选择复核方式”，不会自动产生API费用。
2. 选择“API自动复核”时，填写服务商、模型和API密钥，再点击“按所选方式开始复核”。
3. 选择“Codex / WorkBuddy工作台复核”时，不需要在Agent中填写API密钥；点击“按所选方式开始复核”后，状态会显示“等待工作台复核”。
4. 选择“暂不复核”时，只生成采集结果和基础摘要。
5. 以上三个入口都只处理已经完成的本轮工作簿，不会重新扫描列表或重新采集。
6. 在“工作台接管”栏目选择Codex或WorkBuddy，点击“复制工作台复核口令”，把整段口令粘贴到相应工作台。
7. 工作台只处理Agent导出的候选记录，不会重新进行一轮采集；每完成一条都会保存断点。
8. 全部候选完成后，工作台会调用Agent的结果应用命令，校验结果、更新Excel、每日摘要和异常报告。若尚有候选未处理，Agent会明确提示缺少多少条，并拒绝提前结束。

## 查看和重置高水位

- “输出高水位链接”第一次点击会展开，再次点击会隐藏。
- 第一次使用或需要调整扫描终点时，点击“重置当前范围高水位”，逐条填入并核对链接后保存。
- 全省标准采集继续使用主状态中的高水位；小范围定制任务按平台、类别和城市建立独立状态文件，两者互不覆盖。
# 开始新的采集、继续上次采集与小范围采集

1. 每天第一次正式运行，或者需要在同一天另开一个增量批次时，点击“开始新的采集”。系统会自动建立批次、将本次计数归零并立即采集。第一次使用`YYYYMMDD`目录；同日后续批次依次使用`YYYYMMDD（1）`、`YYYYMMDD（2）`，不会覆盖或混写旧结果。
2. 因断网、验证码、暂停或程序异常继续同一批任务时，页面才会显示“继续上次采集”。点击它可从原断点继续；不要点击“开始新的采集”，否则会另建一个批次。
3. AI复核若卡在登录或滑块验证，页面会显示“中止并重新选择AI复核”。该操作仅关闭本次复核进程，保留采集Excel、高水位与复核队列，并退回复核方式选择；不会重新采集。
4. 500 条时程序暂停并要求核对高水位；确认无误后可继续。当前批次超过 800 条时强制停止。
4. 全省任务选择“全省标准采集”；当前福建省任务继续使用原有 12 条高水位。
5. 小范围任务选择平台、类别、省份和地级市。每个“平台 × 类别 × 城市”是一组，每组填写“即将开始、已结束”两条链接。例如阿里资产、住宅和商业、福州和泉州为 4 组、共 8 条状态链接。
6. 小范围任务保存在独立状态空间，不会覆盖全省生产高水位。
7. 点击开始后，系统先扫描列表并核对高水位，再显示计划条数和预计时间，然后采集详情。
8. 预计时间按每条 5–7 秒计算，不含登录、验证码、网络等待和复杂页面重试。
