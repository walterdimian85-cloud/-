# 通用模型调用约定

使用本Skill时，把业务判断交给已测试的CLI，不要根据网页文字自行重写采集逻辑。

1. 确认宿主环境具备Node.js、文件系统、Microsoft Edge和运行本地命令的能力。
2. 先运行`node bin/auction-cli.mjs help`确认环境。
3. 运行采集前检查所选平台的全部高水位；缺失时逐项询问用户，不打开浏览器。
4. 使用`--config config/example.json`或等价命令启动CLI。
5. 登录、短信码和滑块验证必须交由用户人工完成。
6. 根据CLI退出码、进度JSON和运行结果汇报状态，不从技术日志猜测成功。
7. 不修改成交判断、面积优先级、字段结构或高水位，除非用户明确要求开发新版本。

只有聊天能力、不能执行命令或控制浏览器的模型不得声称已经完成采集。
