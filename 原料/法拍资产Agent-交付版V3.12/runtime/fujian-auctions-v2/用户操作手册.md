# 福建法拍房整理 Skill V1.1.0 用户操作手册

## 1. 这个 Skill 能做什么

本 Skill 使用 Microsoft Edge，以只读方式采集阿里资产和京东拍卖中福建省司法拍卖房产的每日新增及新结束数据，并生成统一 Excel 工作簿。支持住宅用房、商业用房、工业用房，以及“即将开始”“已结束”两种状态；支持高水位增量、逐条保存、断点恢复和字段质量检查。

默认不采集债权人、债务人，不采集“正在进行”，不收录阿里“资产交易”栏目。账号只用于读取页面，禁止报名、出价、收藏、设置提醒、联系机构或修改账号。

## 2. 安装前准备

- Windows 10/11。
- Microsoft Edge。
- Node.js 20或更高版本。
- WorkBuddy，以及能执行本地命令的DeepSeek或HY3模型。
- 一个放置状态的外部目录和一个放置结果的外部目录。不要把真实Edge Profile、Cookie、高水位或每日结果放入Skill目录。

升级前应禁用或移除旧名称`collect-fujian-auctions-v1`，避免两个版本同时被模型触发。

## 3. 安装

1. 在WorkBuddy中选择“安装本地Skill”，导入`fujian-auctions-v1.1.0.zip`。
2. 确认安装后的Skill名称为`fujian-auctions`，且目录中能看到`SKILL.md`、`package.json`、`bin/auction-cli.mjs`和`scripts/workbuddy_probe.mjs`。
3. 为Skill授予本地执行权限，并为状态目录、结果目录授予读写权限。
4. 首次安装依赖时，在Skill根目录运行`npm ci`。发行包不包含`node_modules`，这是正常的。

### 第一次采集前选择结果目录

新用户第一次提出采集任务时，WorkBuddy应先询问：

```text
今后爬取的房源信息希望保存在哪个文件夹？请提供完整文件夹路径；程序会记住该位置，后续每日结果继续保存在这里。
```

用户没有回答前不得打开拍卖网站。用户提供路径后，第一次运行增加：

```text
--output-dir "<用户指定的结果目录>"
```

该选择会保存在外部状态目录的`output-settings.json`中，以后不再重复询问。用户希望更换结果目录时，只需明确提供新路径并再次使用`--output-dir`。不得把结果目录设在Skill安装目录内。

## 4. 第一次能力探针

把下面整段话复制给WorkBuddy；把尖括号内路径改成您自己的真实路径。

```text
请使用 fujian-auctions Skill，只做安装能力探针，不打开任何拍卖网站，不采集数据，不读取Edge账号内容，也不修改高水位。

Skill根目录请自行定位。状态目录为：<状态目录>
结果目录为：<结果目录>

先确认Node.js版本；如依赖缺失，在Skill根目录执行npm ci。随后执行：
node scripts/workbuddy_probe.mjs --state-dir "<状态目录>" --output-dir "<结果目录>"

请原样返回完整JSON，并逐项说明：Node是否为20以上、CLI是否可调用、Edge是否找到、两个目录是否可写、最终ok是否为true。CleanupWarning只作为清理警告，不应误判为目录不可写。不得使用Agent Browser。
```

安装成功的核心标志是：

```json
{
  "ok": true,
  "nodeMajorSupported": true,
  "stateWritable": true,
  "outputWritable": true,
  "cliCallable": true
}
```

同时`edgePath`应指向本机`msedge.exe`。如果只有`stateCleanupWarning`或`outputCleanupWarning`，但上述两项Writable为true，可以继续。

## 5. 离线回归测试

能力探针通过后，把下面的话复制给WorkBuddy：

```text
请使用 fujian-auctions Skill进行离线回归测试。不要打开拍卖网站，不读取或修改生产state.json，不调用Agent Browser。

在Skill根目录检查`tests/fixtures/curated-html`中的四份福州/泉州人工整理HTML、`tests/fixtures/curated-training`中的标准答案、`assets/所有小区名称清单.txt`和`tests/fixtures/special-cases.json`均存在，然后运行：
npm run test:regression

请返回完整原始输出和真实退出代码。只有固定样本与专项样本都显示passed且退出代码为0，才能判断通过。
```

正确结果应包含：

```text
Fuzhou/Quanzhou curated HTML regression samples passed
special regression cases passed
EXIT_CODE=0
```

## 6. 最小在线试运行

试运行的高水位由用户提供，模型不得自动创建、猜测、搜索或从生产状态复制。

先复制以下提示：

```text
请使用 fujian-auctions Skill进行最小在线试运行。目前先不要打开网站。请先询问我要测试的平台、类别和状态，然后明确告诉我还需要提供哪个组合的高水位链接。收到链接前不要运行采集。

收到链接后，请把它写入生产目录之外的独立试运行状态目录，records保持为空；使用独立输出目录、--dry-run、--low-frequency、--headed、--max-items 1和合理的--max-pages运行。运行前后计算生产state.json的SHA-256，禁止修改生产状态，禁止使用--restart或Agent Browser，禁止发生任何账号写操作。
```

WorkBuddy应先向您提问，例如：

```text
本次试运行还缺少阿里资产住宅用房—即将开始的高水位链接，请您提供链接。收到后我会写入独立试运行状态，不会修改生产高水位。
```

您随后发送当前列表中可找到的高水位链接即可。如果希望验证“确实写入一条新数据”，请自行提供列表第二条或更靠后的链接；若提供列表第一条，0条新增同样是合法结果。

试运行通过必须同时满足：真实退出代码为0、`anchorFound=true`、`failures=[]`、`dryRun=true`、`stateAdvanced=false`、生产`state.json`前后校验值一致，并且没有账号写操作。

## 7. 首次正式运行前准备高水位

正式采集需要两个平台、三个类别、两个状态共12条前一日高水位：

- 阿里资产：住宅/商业/工业 × 即将开始/已结束，共6条。
- 京东拍卖：住宅/商业/工业 × 即将开始/已结束，共6条。

如果只运行一个平台，则该平台6条必须齐全。缺失时，Skill应逐项指出，例如“还缺少前一日京东拍卖工业用房—已结束的最新数据链接”。高水位未齐全前不得打开网站。

## 8. 每日正式采集提示词

确认高水位有效后，把下面的话复制给WorkBuddy：

```text
请使用 fujian-auctions Skill正式采集今天福建省法拍房数据，平台为阿里资产和京东拍卖，类别为住宅用房、商业用房、工业用房，状态为即将开始和已结束。使用Microsoft Edge、外部持久Profile、低频模式、逐条保存和本地Supervisor监工，最终合并到同一工作簿。

开始前检查状态目录中是否已有结果保存位置。若这是第一次运行且没有历史设置，请先询问我今后要把房源信息保存在哪个文件夹；收到我的明确路径后再以--output-dir传入。不得自行猜测或保存到Skill目录。

开始前先检查12条前一日高水位。若缺失或无效，请逐项指出平台、类别和状态并停止，不要猜测。若出现账号密码、短信码、验证码或滑块，请暂停并让我人工完成。不得使用Agent Browser替代CLI，不得自动绕过验证，不得报名、出价、收藏、提醒或联系机构。

状态目录：<状态目录>
结果目录：<已有历史设置；首次运行则由用户回答>

请通过`node bin/auction-cli.mjs supervise`启动正式任务，不要直接后台运行`run`后结束监控。若发现同日采集进度，请从断点继续，禁止自行使用--restart。Supervisor负责心跳、单实例锁、停滞检测和有限自动重试。完成后请报告真实退出代码、总表/即将开始/已结束/待复核数量、failures、stateAdvanced、重试次数、最终工作簿路径以及新高水位摘要。
```

正式运行成功应满足：退出代码为0、`failures=[]`、工作簿四个分表存在且格式检查通过、`stateAdvanced=true`。若任一列表没有找到高水位或存在关键失败，状态不得推进，也不得宣称完整成功。

## 9. 监工、自动续爬与人工验证

- 网络中断、Edge异常关闭或程序意外退出：Supervisor按原命令自动重启，并读取`采集进度.json`继续；不要默认从头开始。
- 状态目录中的`任务状态.json`每30秒更新一次，是用户和模型查询任务进度的首选文件。
- 同一天重复启动时，进程锁会阻止第二个采集任务；模型应返回现有任务状态。
- 默认连续20分钟没有控制台活动和进度更新才视为停滞；默认最多自动重试5次。
- 登录页提供“快捷登录”：仅在用户已授权且页面明确提供该按钮时可点击一次。
- 账号密码、短信码、验证码、滑块：必须由用户人工完成。
- Excel被占用：关闭工作簿后继续同一任务。
- 找不到高水位：不要扩大解释或更换链接；让用户提供正确链接后再继续。

查询进度时可复制给WorkBuddy：

```text
请使用fujian-auctions Skill检查当前采集进度。先读取外部状态目录中的任务状态.json；如需明细再读取今天的采集进度.json和运行结果.json。请报告任务状态、最后心跳、当前平台/类别/状态、已完成数量、失败数量、重试次数、是否需要人工处理和最终工作簿路径。不要重新启动任务，也不要仅根据历史对话推断。
```

## 10. 每日结果

最终文件保存为：

```text
<结果目录>\YYYYMMDD\YYYYMMDD新增房源信息.xlsx
```

工作簿包含`总表`、`即将开始`、`已结束`、`待复核`四张表。JSON进度、证据与运行结果用于断点恢复和审计，正式结果确认无误后可按团队留档制度处理，但运行中的进度文件不要删除。
