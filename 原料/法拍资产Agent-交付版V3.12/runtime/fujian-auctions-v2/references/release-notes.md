# V1.1.0发行说明

## 本地监工

- 新增Supervisor正式运行入口、30秒状态心跳和`任务状态.json`。
- 新增每日单实例锁，避免重复启动两套浏览器和采集任务。
- 新增停滞检测、有限自动重试及基于`采集进度.json`的无损续爬。
- 登录验证和高水位等人工门禁不会被无限重试。
- 完成、需要处理及重试耗尽时提供Windows桌面通知。
- WorkBuddy对话结束后，本地监工继续执行，不需要模型持续消耗Token轮询。

## 本次更新

- 新增首次运行结果目录门禁：未获得用户明确路径且无历史设置时，在打开Edge前停止。
- 用户选择保存到外部`stateDir\output-settings.json`，后续运行自动复用，仍可显式更换。
- 标题不再删除街道、社区、镇、乡、村。
- 括号内小区、楼盘、楼栋、单元、房号、商铺、车位、园区和项目期数等定位内容予以保留；原址、现址、门牌号说明和权证内容继续删除。
- 增加“黄花山路45号（大潭映象16幢1单元402室）”与“潭城街道景贤路288号（正达·名郡25幢1单元19层1902房）”回归样本。

## 验证结论

- 福州/泉州房源上新与法拍结果四份人工整理HTML、标准化记录快照及小区名称数据库回归通过。
- 高水位缺失、断点恢复、流拍、成交、面积文本/表格、资产交易排除等专项样本通过。
- Excel四表、公式、格式与打开兼容性检查通过。
- WorkBuddy能力探针通过。
- DeepSeek-V4-Pro与HY3离线回归、零新增和一条新增影子试跑通过。

## 已知依赖告警

`npm audit`报告2个中等级告警，均源于ExcelJS 4.4.0间接依赖的旧版`uuid`。告警对应UUID v3/v5/v6在调用者主动传入缓冲区时的边界检查问题；本Skill不调用该接口。当前审计工具给出的修复方案会把ExcelJS降至3.4.0并引入兼容性变化，因此V1.0不采用强制修复。后续在ExcelJS提供兼容升级路径时重新评估。

## 安全边界

发行包不包含真实Edge Profile、Cookie、账号信息、高水位、每日结果、运行日志、截图、临时工作簿或`node_modules`。验证码、短信码、账号密码和滑块只允许用户人工处理。
