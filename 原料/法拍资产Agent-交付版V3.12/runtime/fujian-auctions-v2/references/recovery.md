# 中断恢复

正式任务默认由Supervisor自动重新执行与中断前相同的命令和配置。程序读取当日`采集进度.json`，复用列表队列并跳过已完成链接。监工规则见[本地监工与自动续爬](supervisor.md)。

- 不得默认使用`--restart`。
- 临时Excel被占用时，以JSON进度为恢复依据。
- 登录或验证码出现时保留浏览器和进度，等待用户人工完成。
- 筛选被认证页面清空时重新建立筛选，不使用未确认列表。
- 只有全部分组、详情、Excel和QA成功后才推进高水位。
- `任务状态.json`为用户和AI查询任务状态的首选入口；不要仅凭进程存在或普通日志宣称完成。

Edge历史恢复工具属于内部开发工具，不是v1正常恢复机制，也不进入公开发行包。
# 跳过历史刷新

用户明确说明旧状态库未及时更新、要求只按新提供的前一日高水位扫描时，可在恢复命令中加入`--skip-historical-refresh`。该参数只跳过状态库内旧“即将开始/正在进行”记录的详情刷新，不跳过任何平台、类别或状态的高水位列表扫描，也不清空已保存断点。不得由模型自行启用。
