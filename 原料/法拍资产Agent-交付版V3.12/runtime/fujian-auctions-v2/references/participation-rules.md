# 报名人数与竞买记录规则

## 适用范围

- 仅对`已结束`标的提取并输出`竞买记录、报名人数`。
- `即将开始`尚不能形成最终统计，两列必须留空，不得写0或当前临时人数。
- 两列均为非负整数：竞买记录单位为`次`，报名人数单位为`人`。

## 页面证据

### 阿里资产

1. 报名人数优先读取详情页主图右侧、结果灰色区下方、设置提醒人数左侧的`N人报名`；兼容`报名人数：N人`。
2. 竞买记录读取详情页标签栏中的`竞买记录（N）`；兼容半角括号、`竞买记录：N`以及网页错写的`应买记录（N）/应买记录：N`。
3. 不得把`设置提醒`或`围观`人数误认为报名人数。

### 京东拍卖

读取详情页明确的`N人报名/报名人数N`。京东页面的`出价记录（N）`与业务字段`竞买记录`含义相同，必须将其数值写入Excel的`竞买记录`列；两个平台同时兼容`竞买记录（N）/应买记录（N）/竞价记录（N）/出价记录（N）`。没有明确标签时写`未找到`并进入字段复核，不得从成交价、延时次数或关注人数推算。

## 状态约束与冲突处理

- 已成交：报名人数和竞买记录正常应大于0；任一缺失或为0时保留页面原值并进入复核，不得自行改成1。
- 已流拍：竞买记录固定为0，因为没有有效出价；报名人数仍以页面明确值为准，可能大于0，不得因流拍推断为0。
- 页面明确数值与业务特征冲突时，页面原始证据优先，但必须标记复核。
- 只提取汇总次数，不抓取竞买人编号、逐次出价明细或其他个人信息。
