## V2活动回归样本

V1曾使用20260802、20260803每日工作簿作为早期回归样本；V2不再携带或执行这两组旧样本。当前活动回归基线改为：

- `福州房源上新.html`；
- `泉州房源上新.html`；
- `福州法拍结果.html`；
- `泉州法拍结果.html`；
- 上述HTML生成的标准化记录快照与竞买参与数据标准答案；
- `所有小区名称清单.txt`及生成后的结构化小区数据库。

四份HTML的文件大小、SHA-256和预期记录数量统一记录在`tests/fixtures/curated-html/manifest.json`，回归程序运行时必须逐项校验。

## 不得退化的能力

- 两个平台、三个网站类别、两种状态与十二项高水位。
- 逐条保存、断点恢复、Supervisor 监工和生产状态保护。
- 阿里“资产交易”排除与两平台成交/流拍证据规则。
- Excel 的总表、即将开始、已结束、待复核四表及公式、排序和格式。
- 用户人工完成账号密码、短信码、验证码和滑块；程序只读使用账号。

V2人工整理HTML与标准答案用于发现无意变化；经用户确认的字段修正必须同步更新来源说明和测试，不能只改快照来掩盖解析差异。
