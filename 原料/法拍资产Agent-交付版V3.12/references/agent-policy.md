# 单Agent业务边界

- 仅在用户点击“开始”或明确执行`start`后运行，不创建定时任务。
- V2 Skill目录是只读依赖；Agent不得编辑、覆盖或向其中写入文件。
- 采集由V2 CLI完成。Agent只负责启动、监工、数量门禁、集中复核、历史归档和报告。
- 单次任务最长4小时；可恢复中断最多自动重试5次。
- 验证码、滑块、短信码和账号密码必须由用户人工处理。等待超过1小时后保持暂停，用户点击继续后断点续爬。
- 记录数超过500条时暂停并要求确认高水位；确认后可续爬。超过600条无条件叫停。
- 只有V2报告全部高水位命中、`failures=[]`且生产状态成功推进，采集阶段才算完成。
- 疑难记录不得阻塞列表采集；完成列表采集后集中复核。
- AI重点复核面积、标的名称和小区名称。高置信度且有页面证据时才自动写回；其他建议进入异常报告。
- 所有AI修改必须保存修改前值、修改后值、证据原文、置信度、规则说明和时间。
- 禁止报名、出价、收藏、设置提醒、联系机构、修改账号或绕过平台验证。
